# 集聚效益可视化

> 城市规模如何改变你的生活？从月薪、房租到外卖、孤独感 —— 用数据看见集聚的力量。

本项目通过交互式可视化，展示**集聚效益（Agglomeration Economies）**在日常生活中的体现。不谈抽象的经济学理论，只看你每天能感受到的东西：工资、房租、外卖、看病、社交、夜生活……

---

## 这个页面讲了什么？

页面按以下顺序展开，每个部分都是一个**你可能在生活中讨论过的话题**：

### 1. 城市标度律 — "为什么大城市赚钱多？"
- 用散点图展示 200 个城市的人口 vs GDP 关系
- **核心发现**: 标度律指数 β = 1.102 > 1，意味着城市人口每增长 1%，经济产出增长 1.10%，多出的 0.10% 就是集聚带来的"额外红利"
- 一条拟合线 + 一条参考线，一眼看出"超线性增长"

### 2. 生活体验雷达图 — "大城市生活真的好？"
- 四类城市在 6 个维度的雷达图对比：外卖速度、收入、娱乐、社交、便利、通勤
- **核心发现**: 大城市几乎全面碾压，唯独"通勤时间"是短板

### 3. 月薪 vs 房租 — "赚得多，花得也多"
- 柱状图对比四类城市的月薪、房租和每月可存钱
- **核心发现**: 月薪涨 3.7 倍，房租涨 10 倍；一线城市每月存 4,000 元，县城存 1,500 元

### 4. 便利 vs 通勤 — "痛并快乐着"
- 双轴图：生活便利指数随城市规模上升，通勤时间也在增加
- **核心发现**: 你在用通勤时间换生活便利 —— 愿意换多少？

### 5. AB面对比 — "小城 vs 大城，各有所长"
- 左右双栏 PK：小县城占优的 6 项 vs 一线城市占优的 6 项
- **核心发现**: 小县城赢在通勤、房租、邻里关系；大城市赢在收入、医疗、娱乐

### 6. 孤独感悖论 — "人越多，越孤独？"
- 微信好友增多，但每周见面的朋友减少，孤独感上升
- **核心发现**: 集聚让选择变多，却也让关系变浅

### 7. 夜生活 — "城市越大，夜越精彩"
- 酒吧密度、深夜营业比例、24h 便利店对比
- **核心发现**: 一线城市每 3 家店就有 1 家深夜营业，小县城凌晨两点只有路灯

### 8. 医疗与教育 — "资源红利 vs 竞争焦虑"
- 三甲医院、985 大学、学区房溢价、补习班密度
- **核心发现**: 资源集中在大城市，但竞争也更激烈 —— 学区房溢价达 12,000 元/㎡

### 9. 菜市场经济学 — "大城市反而更便宜？"
- 猪肉价格、蔬菜种类、生鲜电商覆盖率
- **核心发现**: 物流集聚效应使一线城市猪肉反而比县城便宜，蔬菜种类多 3 倍

### 10. 人生选择计分卡 — "按你的价值观打分"
- 12 个维度加权评分表，用星级直观呈现
- **核心发现**: 没有标准答案，权重不同结论不同 —— 你的权重就是你的选择

## 如何使用

### 在线访问
直接打开页面顶部的 GitHub Pages 链接，无需安装任何东西。

### 本地运行
```bash
git clone https://github.com/your-username/agglomeration-economy-visualization.git
cd agglomeration-economy-visualization
# 方式1: 用浏览器直接打开 index.html
# 方式2: 启动本地服务器
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

### 数据说明
- 页面中的数据为**模拟数据**，基于真实统计规律生成（对数正态分布、标度律等）
- 模拟脚本见 `agglomeration_simulation.py` 和 `daily_life_agglomeration.py`
- 如需替换为真实数据，可参考以下数据源：
  - [国家统计局](https://data.stats.gov.cn) — 城市 GDP、人口、就业
  - [中国城市统计年鉴](http://www.stats.gov.cn) — 城市层面经济数据
  - [百度迁徙数据](https://qianxi.baidu.com) — 城市间人口流动
  - [World Bank Open Data](https://data.worldbank.org) — 国际对比数据

## 关于集聚效益

集聚效益（Agglomeration Economies）是城市经济学的核心概念：人口和产业在城市集中后，会产生**超出个体之和的效果** —— 生产效率提升、创新加速、选择增多、成本（部分）下降。

> 城市人口每增长 1%，经济产出增长 1.10%。多出来的 0.10%，就是集聚的魔力。

但这种魔力不是无限的 —— 通勤变长、房租飙升、孤独感上升，都是集聚的"代价"。**每个人都在用自己的选择给集聚效益投票。**
