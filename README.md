# 集聚效益可视化 & 数据家族

> 城市规模如何改变你的生活？从底层理论到高层数据，构建完整的集聚效益知识体系。

本项目包含三部分内容：

1. **知识框架**: 6 层理论体系，从 Marshall (1890) 到 Bettencourt (2007)
2. **数据家族**: 5 层级、42,900 条记录、100+ 指标的模拟数据集
3. **交互可视化**: 10+ 个图表展示普通人能感知的集聚效益

## 数据家族

### 5 层级数据概览

| 层级 | 名称 | 记录数 | 核心指标 | 文件 |
|------|------|:------:|:---------|:-----|
| **Tier 1** | 跨城市面板数据 | 4,000 | 人口、GDP、工资、专利、就业、基础设施 | `T1_跨城市面板.csv` |
| **Tier 2** | 产业集聚数据 | 4,000 | 就业、产值、区位商 LQ、HHI | `T2_产业集聚.csv` |
| **Tier 3** | 企业微观数据 | 5,000 | TFP、集聚溢出、供应链距离、R&D | `T3_企业微观.csv` |

**总计**: 42,900 条记录 · 200 城市 · 100+ 指标 · 5 层级

### 数据生成方法

数据基于 `agglomeration_data_family.py` 生成，核心逻辑：

- **城市标度律**: $Y = Y_0 \cdot N^\beta \cdot \epsilon$，GDP 的 β = 1.07，专利的 β = 1.25
- **产业区位商**: 基于城市规模分配产业权重，大城市偏向高科技和服务业
- **企业 TFP**: 受集聚溢出效应影响（同城市同行业企业越多，TFP 越高）
- **个体幸福感**: 存在倒 U 型关系——人口约 70 万时幸福感最高
- **城际联系**: 基于引力模型 $F_{ij} = G \cdot P_i \cdot P_j / d_{ij}^\gamma$

## 如何使用

### 在线访问
直接打开页面顶部的 GitHub Pages 链接。

### 本地运行
```bash
git clone https://github.com/Wadesha/agglomeration-economy-visualization.git
cd agglomeration-economy-visualization
# 方式1: 浏览器直接打开 index.html
# 方式2: 启动本地服务器
python3 -m http.server 8000
# 访问 http://localhost:8000
```

### 生成数据家族
```bash
pip install numpy pandas scipy
python3 agglomeration_data_family.py
```

## 理论谱系

集聚效益研究跨越 130 年，以下是关键里程碑：

| 年份 | 学者 | 贡献 |
|:----:|------|------|
| 1890 | Alfred Marshall | 提出三大集聚来源：劳动力池、供应商共享、知识溢出 |
| 1937 | Edgar Hoover | 分类：城市化经济 vs 地方化经济 vs 内部规模经济 |
| 1969 | Jane Jacobs | 强调城市多样性的重要性（Jacobs Externalities） |
| 1992 | Edward Glaeser et al. | 实证检验 Jacobs vs MAR 外部性对城市增长的影响 |
| 1997 | Ellison & Glaeser | 提出 EG 集聚指数，量化产业集聚水平 |
| 2007 | Luis Bettencourt et al. | 城市标度律：人口与产出/创新/基础设施的幂律关系 |
